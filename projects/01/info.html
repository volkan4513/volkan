How it works · Project 01

BMW M3 GTR

A car configurator built in the Godot engine and exported to the web.

What it is

A 3D BMW M3 GTR you can orbit, repaint, change wheels on, steer, open the doors of and sit inside. The whole interface is built by code in Godot and the result runs in the browser as WebAssembly. A CRT-style filter gives it a retro look.

Files and loading

FileRole
projects/01/index.htmlGodot web page: loads the engine, shows a progress bar.
index.js, index.wasm (about 43 MB), index.pck (about 24 MB)The engine, and the packed game data (models, textures, scripts).
godot_project/BMW_M3_GTR/The Godot source project: scene, scripts, shader and web export settings.
  • Single-threaded web export, so it needs no special server headers.
  • The three big files are in the offline "heavy" list: saved on first use, or all at once from the main page.
  • The page does not load the shared HOME button, so use the browser back button.

Controls

  • Drag to orbit the car. Mouse wheel or two-finger pinch zooms (limits 2.5 to 6 units).
  • Interior view: the camera moves to the driver's seat. Drag to look around (full turn sideways, 85° up and down), wheel changes field of view (60° to 110°).

How it works

  • Scripts (all in godot_project/BMW_M3_GTR/Scripts/): hud.gd builds the whole interface in code, camera_3d3.gd is the orbit and interior camera, reset_scene.gd, rotate_object_multiple.gd (swings the doors) and FPS.gd.
  • Paint shader: a custom spatial shader swaps the body colour and the stripe colour of the car's paint texture independently. It finds the navy stripe pixels by how blue they are, and can draw centre or dual stripes from the texture's horizontal coordinate.
  • Steering: the front wheels are part of merged meshes, so at startup the game splits them out by measuring each triangle's distance from the wheel centre. That lets them turn.
  • Speed: tools/merge_car_meshes.gd is an editor script that merges the car meshes by material, cutting roughly 195 draw calls to about 30. A black veil hides the first-frame hitch.

Changing it

  • Open godot_project/BMW_M3_GTR/project.godot in Godot 4, edit, then export for web into export/.
  • Copy the exported index.html, .js, .wasm, .pck and the audio worklet into projects/01/, then run python tools/build_offline_manifest.py.

Page startup in detail

This index.html is the standard Godot 4 web export template; the configuration object it passes to new Engine() is worth knowing.

SettingValueMeaning
executable"index"The engine loads index.wasm and index.pck by this base name.
fileSizespck 24,056,752 bytes, wasm 43,016,933 bytesUsed for the progress bar total. If you re-export, these numbers are regenerated.
GODOT_THREADS_ENABLEDfalseSingle-threaded build; ensureCrossOriginIsolationHeaders is also false, so no service worker or COOP/COEP headers are needed.
canvasResizePolicy2Adaptive: the canvas follows the window size.
focusCanvastrueThe canvas takes keyboard focus on start.
args, gdextensionLibsboth emptyNo command-line arguments and no native extensions.
  1. The page first calls Engine.getMissingFeatures(). If the browser lacks something (for example WebGL2 or WebAssembly), a red notice lists the missing features instead of starting the game.
  2. Otherwise the overlay shows index.png as a splash and a <progress> bar. onProgress(current, total) sets its value, or makes it indeterminate when the size is unknown.
  3. When startGame() resolves the overlay is removed; if it rejects, the error text is shown in the notice box.
  • The viewport meta has user-scalable=no and the body has touch-action: none and overflow: hidden, so the page itself never scrolls or pinch-zooms; touch gestures go to the game (orbit and pinch zoom).
  • The page includes ../../info-link.js with data-info="info.html", which adds the link to this page.
  • Icons: index.icon.png is the tab icon and index.apple-touch-icon.png the iOS home-screen icon.

Limits and edge cases

  • The download is about 67 MB (wasm + pck), so first load on a slow connection shows the progress bar for a long time; later loads depend on the browser or offline cache.
  • The engine handles all of the car code, input, stats and persistence internally. Nothing on the web page reads or writes localStorage, and there are no URL options.
  • The Godot source project (godot_project/) is not inside projects/01/; only the exported build is here, so the script details above come from the author's source, not from files in this folder.
  • If the engine throws while starting (out-of-memory on a weak phone, no WebGL2), the notice box shows the error message and the game does not start.

How it differs from the other projects

The only project made with a full game engine (Godot) rather than hand-written JavaScript, so it is by far the heaviest download, about 67 MB, but gets real engine features like shaders and a scene editor for free.

Main quality

A full in-engine car configurator with a custom paint shader, steering wheels and an interior view, with a retro CRT filter.

How it works · Project 05

Windows 98

A working Windows 98 desktop inside a CRT monitor.

What it is

A Windows 98 desktop with a boot sequence, Start menu, draggable windows and a set of working apps (Paint, Minesweeper, Notepad, Media Player, Internet Explorer, MS-DOS prompt). It sits inside a photo of a CRT monitor.

Files

FileRole
index.htmlWrapper: the monitor image with the desktop in an iframe. On phones the monitor is hidden and the desktop fills the screen.
windows98.htmlThe whole desktop: window manager, Start menu, apps, boot, screensaver (about 2850 lines).
paint.htmlThe Paint app, loaded as an iframe inside a window.

How the desktop works

  • Windows: createWindow makes a window with title bar, drag, resize, minimise, maximise and a taskbar button. Dialogs use msgBox.
  • Icons: open on double-click, tap or Enter. Right-click (or long press) opens a menu with New Text Document and Properties.
  • Start menu and quick-launch bar, clock updated every 15 seconds, Esc closes menus.
  • Boot sequence at start, shut down and restart.
  • Screensaver: a starfield after 120 seconds idle (set in the Display control panel).
  • Saving: settings are stored in localStorage under keys starting with w98..

How index.html wraps windows98.html

  • index.html shows page_images/monitor_03.webp (1536x1024, ratio 1.5) with a .screen div positioned at top 11%, left 24.7%, width 51.25%, height 53.25% of the image. An iframe (allow="autoplay; fullscreen") loads windows98.html inside it. The frame is sized min(100vw, 100vh * 1.5), so it always fits the viewport.
  • A CSS vignette (--vignette-opacity: 0.3) is an ::after overlay with pointer-events:none, so the desktop stays clickable.
  • Phone mode (media query: width up to 760px, or portrait up to 1100px, or height up to 480px): the monitor image is hidden, the frame becomes fixed full screen with a thin bezel (6px padding, safe-area aware, rounded 14px) and the site home button is hidden because the desktop has its own Back to Portfolio icon.
  • Because the desktop lives in an iframe, navigation out of it (Back to Portfolio, Parking Puzzle) goes through goTop(url), which uses window.top.PixelTransition.go when available, else sets window.top.location, falling back to the iframe own location if the top window is not reachable.

Window manager details

  • createWindow(opts) options seen in the code: title, icon, width, height, menu, status, body, noMin, fixedSize (no maximise button and no resize grip), autoHeight, onClose, onResize, appId. Windows live in a windows Set; zTop starts at 10 and increases on focus.
  • Drag: pointer events on the title bar with pointer capture. At least 60px of the window stays reachable horizontally and the title bar cannot go above the top or below (height - 24px). Dragging is disabled when maximised or on a small screen.
  • Resize: the bottom-right grip, minimum 200 x 120 px; calls onResize if the app defines one.
  • Small screens: isSmall() is true when the desktop is narrower than 640px or shorter than 420px; the small class is toggled on body on every resize (and dragging is off).
  • Clicking inside an iframe (Paint, Internet Explorer) does not fire a pointerdown on the desktop, so a blur listener on window checks whether the active element is an iframe and raises that window.
  • Single-instance apps (single: true: Paint, Minesweeper, Media Player, Display Properties) are tracked in the SINGLE map; opening them again focuses the existing window.
  • Opening items: bindOpen opens on touch with one tap, on double-click with a mouse (ignored for 700ms after a touch open), and on Enter for keyboard focus.

Boot, shut down and screensaver

  • Boot: BIOS-style text lines (Award Modular BIOS, memory test, IDE detect) printed every 120ms, then the logo for 1300ms. Click the boot screen to skip. If the sessionStorage key w98.booted is already set (same tab session) the boot is the fast version (40ms per line, 500ms logo).
  • Shut Down... dialog offers Shut down, Restart, Cancel. Both close all windows; shutting down shows the shutdown screen with Restart and Leave buttons (Leave goes to the portfolio); Restart runs a fast boot.
  • First visit: if seenReadme is not stored, README.txt opens in Notepad 2.6 seconds after load.
  • Screensaver: a canvas starfield of 220 stars (depth step 0.008 per frame, size up to 3px). The idle timer is 120000ms, reset by pointerdown, pointermove, keydown and wheel; input within 800ms after it starts is ignored so the click that started a preview does not close it. Choose (None) in Display Properties to disable it.

Apps in detail

Notepad

Menus File (New, Save, Exit), Edit (Select All, Time/Date F5), Format (Word Wrap toggle), Help. Window 460 x 340. Save downloads a text file through a Blob URL, named after the document if it ends in .txt, otherwise untitled.txt. It also opens README.txt and unfinished_game_ideas.txt (found in My Documents and the Recycle Bin).

Paint (paint.html in an iframe, window 600 x 430)

  • Tools: pencil, eraser, line, fill, rectangle, circle, airbrush. Brush sizes 1, 3, 6 and 10 px. Eraser width is max(8, size*2).
  • Left button draws with the foreground colour, right button with the background colour; the fill tool respects the same buttons. Palette swatches plus a custom colour input (type=color) and an Edit Colors menu item.
  • Airbrush: every 30ms it drops 18 single pixels at a random angle inside radius max(6, size*3).
  • Undo: history of PNG data URLs, maximum 50 steps (Ctrl+Z or Cmd+Z, or the Undo menu item); Clear Canvas fills with the background colour (and is undoable); Save downloads mspaint-drawing.png.
  • The canvas starts at 200 x 150 and a ResizeObserver grows it (never shrinks) to the window size, copying the existing drawing and filling new area with the background colour. Uses pointer events, so touch and pen work.

Minesweeper (window 260 x 300, fixed size)

  • Levels: Beginner 9x9 with 10 mines, Intermediate 16x16 with 40 mines (MINE_LEVELS). The chosen level is stored as w98.mines.level.
  • Mines are placed on the first click (placeMines, partial Fisher-Yates shuffle) and never in the clicked cell or its neighbours, so the first click is always safe and opens an area. Reveal uses an iterative stack flood fill for zero cells.
  • Right-click toggles a flag; on touch a 420ms long press flags (with a short vibration where supported) and a flag-mode button switches taps between open and flag. Face button or F2 restarts; the face changes while a cell is pressed, on loss and on win. LCD counters are clamped to -99..999.
  • Best times per level are saved in w98.mines.best; Game, Best Times... shows them (default text "999 seconds Anonymous").

Media Player

Window 340 x 400. It loads ../04/playlist.js lazily (once) and plays the files from project 04 through an Audio element (preload="none"), so it depends on that folder. Buttons: previous, play, pause, stop, next; seek slider (0-1000), volume slider saved as w98.amp.vol (default 0.8). Tracks advance automatically at the end and wrap around. A 76x16 canvas shows a 19-bar analyser (Web Audio) coloured green, yellow above level 8 and red above level 12. Closing the window stops the audio and closes the audio context.

Internet Explorer (window 640 x 440)

  • The home page is generated HTML (srcdoc) with links to the projects, a visitor counter (w98.visits) and a guestbook: the form posts a message to the desktop, which stores the last 30 entries in w98.guestbook (name cut to 20 characters, message to 80) and reloads the home page. The message handler accepts only same-origin or sandboxed (null origin) senders.
  • Address bar: Enter navigates; text without a scheme and not starting with . or / gets https:// prepended. Back and forward use two stacks. Cross-origin addresses show a notice bar with an "Open it in a new tab" link, and the full-screen action opens same-origin pages in the top window or other pages in a new tab. Project entries (PROJECTS) open inside this browser; Parking Puzzle leaves the desktop.

MS-DOS Prompt (window 560 x 340)

Commands are case-insensitive. The working directory starts at C:\WINDOWS; cd accepts \, .., WINDOWS and PROJECTS. COLOR xy takes two hex digits (background, text) from the 16 DOS colours; COLOR alone resets. START accepts app names (notepad, mspaint/paint, winmine/minesweeper, iexplore, explorer, mplayer/winamp, ...), a project name, or puzzle. Typing an app name alone also starts it; anything unknown prints "Bad command or file name". shutdown runs the shutdown.

Folders and Display Properties

  • My Computer shows A: (not ready error), C: (My Documents, Program Files = list of apps, Windows = hidden warning), PORTFOLIO (D:) = My Projects, Control Panel = Display. The Recycle Bin holds joke files and has Empty Recycle Bin with confirmation (the list is not persisted).
  • Display Properties (fixed size, single instance): wallpaper list (Teal default, Clouds, Black Thatch, Pixel Parking, Purple Haze, Bricks) with live preview, screen saver select (None / Starfield) and Preview. OK/Apply saves w98.wallpaper and w98.saver.

Customising and extending

  • New app: add an entry to APPS with title, icon, optional single and an open() that calls createWindow; then add it to DESKTOP_ITEMS and START_ITEMS (and APPS_BY_CMD for the DOS prompt).
  • Projects list (My Projects, IE home, PROJECTS DOS command): the PROJECTS array; use url to open in IE or top to leave the desktop.
  • Wallpapers: add a CSS background value to WALLPAPERS.
  • Text content: README and GAME_IDEAS constants; idle time: the 120000 in resetIdle; screen position inside the CRT: the percentages on .screen in index.html.
Media Player and the Pixel Parking wallpaper read files from ../04/ and ../../images_to_use/; moving those folders breaks them silently.

How it differs from the other projects

Pure DOM and JavaScript with no canvas engine: it is a small operating system imitation, with its own window manager. It uses iframes for Paint and for the desktop itself.

Main quality

A convincing Windows 98 experience, from the boot screen to a working DOS prompt, framed like a real CRT.
